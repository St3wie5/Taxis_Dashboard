#Roadmap del proyecto 
este proyecto está diseñado para ser un dashboard de administracion de taxis con varios modulos con informacion tanto de los carros como de los choferes . este documento va a servir como una guia para entender las diferentes carpetas del proyecto y que hace cada una funcionando como una guia.

## Fases del Proyecto

1. **Requerimientos y Análisis**
   - Definir qué datos necesita el sistema

2. **Diseño de Base de Datos**
   - Crear diagrama ER (Entity-Relationship)
   - Definir tablas y relaciones

3. **Diseño Visual (Wireframes)**
   - Mockups del dashboard
   - Layout de interfaces

4. **Configuración de Base de Datos**
   - Crear tablas en PostgreSQL
   - Scripts SQL

5. **Desarrollo Backend**
   - APIs en Python
   - Conexión con BD

6. **Desarrollo Frontend**
   - HTML/CSS
   - Consumir APIs

7. **Pruebas y Deployment**
   - Verificar funcionalidad
   - Despliegue
